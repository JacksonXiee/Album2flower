# Album2flower · image-to-bouquet

> 把一张参考图（专辑封面、海报、艺术作品、照片）翻译成一束**花店能真实打出来的花**，并生成一张「左手前举、第一人称手机随拍」风格的成品照。

## 这个 skill 做什么

- 输入：1 张参考图（专辑封面最适合，也支持任意图片）
- 输出：3 个文件，固定风格，不询问你选样式
  - `<source-slug>-bouquet-spec.md` — 花束规格（花材、数量、颜色、角色、采购难度、可替代品、包装层）
  - `<source-slug>-image-prompt.md` — 生成图片时使用的完整精确提示词
  - `<source-slug>-handheld.png` — 第一人称左手前举的手持花束照片（竖版 9:16）

skill 会先把参考图的**视觉关系**（主色/次色/高光/点缀/暗锚、骨架、留白、质感）翻译成可购买的真实花材 + 包装纸，过一道「花店可制作性」闸门（真实品种、有茎、能绑到一点、一只手能握、重力合理），再调用内置图像生成产出照片，最后自检：花 recognizable、茎汇拢、手部解剖合理、镜头一致、光线有出处、不含原图文字/logo/人脸。

## 安装方法

把下面这段话复制给你的智能体助手（推荐 Codex），让它帮你安装：

```text
帮我安装 image-to-bouquet 这个 skill，从 GitHub 仓库 JacksonXiee/Album2flower 的 image-to-bouquet 子目录安装到本地 skills 目录（可使用 skill-installer skill，仓库地址 https://github.com/JacksonXiee/Album2flower.git，子路径 image-to-bouquet）。
```

> 建议使用 **Codex** 安装与运行。其他智能体作者没有试过效果，不保证一致性。

## 使用方法

安装好之后，按你智能体助手「使用 skill」的方式直接调用即可，流程很简单：

1. **上传**一张你想生成花束的图（专辑封面、海报、照片都行）
2. **直接说话**，例如：

   ```text
   使用 image-to-bouquet 把我这张图转成可真实插制的花束，并生成左手前举手机随拍及三件套文件。
   ```

3. skill 会自动完成：读图 → 分析调色板 → 设计花材 → 写规格 → 生成图 → 自检 → 保存三件套
4. 产出默认放在 `outputs/image-to-bouquet/<source-slug>/`，不会覆盖旧版本，重复跑会自动加 `-v2`、`-v3`

如果你用的是 Codex，可以直接用 skill 自带的默认 prompt：

```text
使用 $image-to-bouquet 把我的参考图转成可真实插制的花束，并生成左手前举手机随拍及三件套文件。
```

## 小贴士

- **参考图是「视觉参考」不是「编辑目标」**：skill 不会照搬原图的人脸、文字、logo、艺术画作本身，只借鉴它的色彩比例、骨架、留白、质感、情绪
- **大片非自然颜色**（比如纯蓝、纯紫这种自然界没有的花色）会被优先安排到**包装纸**上，而不是把花染成假色；如必须染色，spec 里会显式披露
- **不会出现**虚构花种、漂浮的纸、不可绑扎的茎、右手、脸、手机本体、镜子、自拍姿势、第二个人
- **只有一种输出风格**：第一人称左手前举 9:16 手机随拍，不会问你选其他风格
- 如果生成图有 1 处关键不变量不达标，skill 会**最多重试 1 次**；仍不达标会如实报告失败，不会硬说成功

## 进阶

- 想自己看分析过程？spec 文件里会写明：主/次/高光/点缀/暗锚各是什么颜色 + 近似 hex + 视觉角色、温度、结构、质感、要忽略的噪点
- 如果装不上 skill，仓库里还提供了 `one-file-context.md`，把整份内容粘给任意多模态助手也能用（自包含，不依赖 skill 系统）
- 可选的 `scripts/extract_palette.py` 需要 Pillow，用来给图做像素频率调色板提取，辅助（不替代）肉眼分析
